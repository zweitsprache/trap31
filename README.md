# trap31

Next.js development project configured with:

- Next.js 16
- TypeScript
- App Router
- ESLint
- Tailwind CSS 4

## Development

Install dependencies (already done once in this workspace):

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Run lint checks:

```bash
npm run lint
```

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm run start
```
